# Google Play Store App Analysis – Power BI

## Project Overview

This project analyzes Google Play Store application data using Microsoft Power BI to understand app performance, user engagement, ratings, installs, categories, and pricing patterns.

The analysis uses a Google Play Store dataset containing information about applications, including their categories, ratings, reviews, number of installs, price, type, content rating, and other app-related attributes.

## Objectives

- Analyze the distribution of apps across different categories.
- Identify categories with the highest number of installs.
- Analyze app ratings across categories.
- Identify apps with the highest number of reviews.
- Compare free and paid applications.
- Understand relationships between installs, reviews, ratings, and app categories.

## Key KPIs

- Total Apps
- Average Rating
- Total Installs
- Total Reviews
- Free Apps %

## Dashboard Analysis

The Power BI dashboard includes:

- Top 5 Categories by Total Installs
- Top 10 Apps by Reviews
- Average Rating by Category
- Free vs Paid Apps
- App category and performance analysis
- Key performance indicators for the overall dataset

## Data Preparation

Data was prepared using Power Query in Power BI. The process included handling missing values, correcting data types, cleaning the dataset, and preparing fields for analysis and visualization.
